## 简介 \{#what-it-is}

Setu（সেতু，意为“桥梁”）服务于向中国供应商采购的孟加拉国小型企业。它计算订单的真实成本，提示现金何时吃紧，比较融资方案，并通过**里程碑托管**（milestone escrow）分阶段向供应商付款。托管是指资金由中立账户保管，收到约定的证明后才释放。

高风险操作始终由人来决定。AI 只负责解释，计算和规则执行由代码完成。

<Callout type="security" title="所有资金均为模拟">
Setu 中的每笔付款、托管余额和贷款都是模拟沙盒记录。没有真实资金流动，也没有训练任何模型。见[模拟沙盒](/docs/zh/getting-started/simulated-sandbox)。
</Callout>

## 解决什么问题 \{#problem}

从中国进货的孟加拉国进口商通常同时面对四个问题。

| 问题 | Setu 的做法 |
|---|---|
| 真实成本不清楚（运费、关税、银行费用、汇率） | 按订单分析到岸成本和毛利 |
| 两次付款之间现金吃紧 | 90 天现金流日历，含缺口和到期提醒 |
| 贷款难以比较 | 按总成本和利率比较融资方案 |
| 向境外陌生方付款风险高：假供应商、伪造单据、被更改的银行账户 | 供应商核查（KYB）、单据取证、里程碑托管、分级审批 |

信用证（LC）能提供这类保护，但小额订单成本偏高。Setu 希望以更低成本提供类似的保护。

## 安全模型 \{#safety}

- **Tier 0 和 Tier 1**（权限级别）自动执行，Tier 1 附带通知。
- **Tier 2** 需要真人一键批准。
- **Tier 3** 需要一次性密码（OTP）和 10 分钟冷静期。

级别由代码根据数据库中的事实判定。单据或邮件中的文字只是数据，绝不是指令。详见[权限级别](/docs/zh/security/permission-tiers)。
