## এটি কী \{#what-it-is}

সেতুতে যেসব শব্দ পাবেন তার সংক্ষিপ্ত সংজ্ঞা। যেখানে গাইড পাতা আছে সেখানে শব্দের সঙ্গে লিংক দেওয়া আছে।

## বাণিজ্য ও অর্থের শব্দ \{#trade}

| শব্দ | অর্থ |
|---|---|
| **LC (letter of credit, ঋণপত্র)** | সঠিক নথি দেখালে বিক্রেতাকে পরিশোধের ব্যাংকের প্রতিশ্রুতি। সেতুর মাইলস্টোন escrow ব্যাংক ছাড়াই অনেকটা এমন সুরক্ষা দেয়। |
| **Escrow (জমা-রাখা তহবিল)** | শর্ত পূরণ পর্যন্ত নিরপেক্ষ পক্ষের কাছে রাখা টাকা। সেতুতে এটি সিমুলেটেড খতিয়ান। দেখুন [কী সিমুলেটেড](/docs/bn/security/what-is-simulated)। |
| **Milestone (মাইলস্টোন)** | ডিলের একটি ধাপ যা পেমেন্টের এক অংশ চালু করে, যেমন উৎপাদন শুরু, জাহাজীকরণ বা পৌঁছানো। সাধারণ ভাগ ৩০/৬০/১০। |
| **Landed cost (ল্যান্ডেড কস্ট)** | আমদানি পণ্য আপনার কাছে পৌঁছানোর মোট খরচ: দাম, ফ্রেইট, শুল্ক, কর ও খালাস। |
| **B/L (bill of lading, জাহাজ রসিদ)** | পণ্য জাহাজে তোলার প্রমাণ হিসেবে বাহকের নথি। সেতু একে জাহাজীকরণের প্রমাণ ধরে। দেখুন [নথি](/docs/bn/buyer/documents)। |
| **Bill of entry (বিল অব এন্ট্রি)** | বাংলাদেশে পণ্য পৌঁছালে জমা দেওয়া কাস্টমস ঘোষণা। সেতু একে পৌঁছানোর প্রমাণ ধরে। |
| **Incoterms (ইনকোটার্মস)** | কে কোন খরচ দেবে ও ঝুঁকি কার, তা বলে দেওয়া আন্তর্জাতিক নিয়ম। **FOB**: বিক্রেতা জাহাজ পর্যন্ত পৌঁছে দেয়, তারপর ফ্রেইট আপনার। **CIF**: বিক্রেতা আপনার বন্দর পর্যন্ত ফ্রেইট ও বিমা দেয়। **EXW**: আপনি বিক্রেতার কারখানা থেকে নিজে নেন এবং সব খরচ বহন করেন। |
| **Proforma invoice (প্রোফর্মা ইনভয়েস)** | উৎপাদনের আগে দাম ও শর্ত ঠিক করার প্রাথমিক ইনভয়েস। এটি প্রথম কিস্তির প্রমাণ। |
| **Packing list (প্যাকিং লিস্ট)** | প্রতিটি প্যাকেটে কী আছে, ওজন ও সংখ্যাসহ তালিকা। B/L-এর সঙ্গে ব্যবহার হয়। |
| **HS code (এইচএস কোড)** | কাস্টমস শুল্ক ও করের জন্য পণ্য শ্রেণিবদ্ধ করার নম্বর। |
| **Beneficiary (প্রাপক)** | যে ব্যাংক অ্যাকাউন্ট ও তার মালিক পেমেন্ট পান। |
| **KYB (know your business, ব্যবসা যাচাই)** | কোম্পানির যাচাই: লাইসেন্স, নামের মিল, অ্যাকাউন্ট, নিষেধাজ্ঞা। ফল Verified, Warning বা Blocked। |
| **KYB badge (KYB ব্যাজ)** | সরবরাহকারীর পাশের লেবেল, যা যাচাইয়ের অবস্থা ও ১০০-র মধ্যে স্কোর দেখায়। |
| **Registry (রেজিস্ট্রি)** | সেতুর ডুপ্লিকেট-অর্থায়ন রেজিস্ট্রি। নথির আঙুলের ছাপ রাখে, যাতে একটি ইনভয়েস দুই ডিল বা দুই ঋণদাতার জামানত না হয়। দেখুন [নথি](/docs/bn/buyer/documents)। |

## নিরাপত্তার শব্দ \{#security}

| শব্দ | অর্থ |
|---|---|
| **Tiers (টিয়ার)** | কাজের নিয়ন্ত্রণের চার স্তর: ০ স্বয়ংক্রিয়, ১ নোটিশসহ স্বয়ংক্রিয়, ২ এক ট্যাপ, ৩ কোডসহ বিরতি। দেখুন [অনুমতির টিয়ার](/docs/bn/security/permission-tiers)। |
| **OTP (ওয়ান-টাইম পাসওয়ার্ড)** | একবার ব্যবহারের ৬ সংখ্যার কোড। Tier 3-এ লাগে। এখানে এটি সিমুলেটেড। |
| **Cooling-off (কুলিং-অফ)** | Tier 3 কাজ চলার আগে বাধ্যতামূলক ১০ মিনিটের বিরতি। এ সময় বাতিল করা যায়। |
| **Audit chain (অডিট শিকল)** | যে লগে প্রতিটি এন্ট্রিতে আগের এন্ট্রির হ্যাশ থাকে, তাই বদল ধরা পড়ে। দেখুন [স্বাক্ষরিত অডিট লগ](/docs/bn/security/signed-audit-log) ও [অডিট লগ](/docs/bn/admin/audit-log)। |
| **Hash (হ্যাশ)** | তথ্যের আঙুলের ছাপ। সামান্য বদলেও ছাপ আলাদা হয়। |
| **Privacy masking (প্রাইভেসি মাস্কিং)** | এআই মডেলের কাছে লেখা যাওয়ার আগে সংবেদনশীল মান টোকেনে বদলানো। দেখুন [প্রাইভেসি মাস্কিং](/docs/bn/security/privacy-masking)। |
| **Prompt injection (প্রম্পট ইনজেকশন)** | এআইকে চালানোর উদ্দেশ্যে নথি বা ইমেইলে লুকানো বা ছদ্মবেশী নির্দেশ। দেখুন [নথি ও ইমেইল শুধু ডেটা](/docs/bn/security/injection-defence)। |
