# Testing rules

## Every phase must
1. Add tests for each new behaviour (happy path + at least one failure/boundary).
2. Run the phase's "Tests to run" commands from `docs/PLAN.md` and paste the one-line summary into `docs/PROGRESS.md`.
3. Leave the suite green. If something is knowingly broken, mark the test `xfail`/`skip` with a reason and log it in PROGRESS.

## Python (`backend/tests/`)
- pytest, pytest-asyncio, httpx `AsyncClient` against the FastAPI app, Hypothesis for money invariants.
- Layout mirrors `app/`: `tests/domain/`, `tests/security/`, `tests/forensics/`, `tests/api/`, `tests/graph/`.
- DB tests use the docker Postgres with a per-test transaction rollback fixture (`tests/conftest.py`); mark `@pytest.mark.db`.
- **LLM calls are mocked in unit tests** (`FakeChatModel` fixture returning canned structured output). Real-model tests are
  marked `@pytest.mark.llm` and excluded by default (`-m "not llm"`); run them only when asked.
- Security tests are mandatory for: every tier trigger + boundary, approval params-hash binding, cooling-off timing
  (freeze time with `time-machine`), audit chain tamper detection, PII never reaching the fake model, injection detector on the 5 attack styles.

## Web (`frontend`)
- Vitest + Testing Library for components (`*.test.tsx` next to the component); mock the API client.
- Accessibility smoke: `@axe-core/playwright` on key pages in e2e.
- Playwright e2e in `frontend/e2e/` — at minimum the demo scenario (Phase 6.2).

## Test data locations
- `backend/seed/*.json` — small, committed demo data.
- `backend/tests/fixtures/` — tiny hand-made fixtures (a few PDFs, ≤ 50 KB each), committed.
- `backend/synth/out/` — generated packs (gitignored). `backend/eval/data/` — eval datasets (gitignored; regenerated by seed).
- `backend/eval/results/` — committed `metrics.json` + `metrics.md` only.
- Never read generated data directories into context; inspect with `ls | head` or summary scripts.

## Commands
`make test` · `uv run --directory backend pytest -q -m "not llm"` · `pnpm --dir frontend test` · `pnpm --dir frontend e2e`
